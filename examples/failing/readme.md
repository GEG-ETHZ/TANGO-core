# failing
This directory is intended to store examples that trigger errors by perturbing values in `../flexible_SF_manual.yml` for files named `../flexible_SF_manual*.yml` and similarly for other files to demonstrate failure modes and show that they are handled appropriately to clarify troubleshooting steps to users.

These examples can be run directly with the python scripts, e.g. `uv run examples/run_flexible_SF_manual.py`.
