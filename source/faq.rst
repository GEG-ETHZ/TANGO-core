TANGO FAQ
=========

Frequently Asked Questions about TANGO.

1. **What is TANGO?**

   TANGO is a framework designed for streamlining simulations and workflows in fluid mechanics, reservoir engineering, and other domains.

2. **How do I install TANGO?**

   Install it via pip:

   .. code-block:: bash

      pip install tango-framework

3. **What are the prerequisites for using TANGO?**

   - Python 3.7 or higher
   - Required libraries installed via pip
   - (Optional) CMG software for specific workflows

4. **Where can I find examples?**

   Examples are available in the :doc:`examples` section.

5. **How do I contribute to TANGO?**

   Contributions are welcome! See the contribution guide on our GitHub repository: https://github.com/your-tango-repo

6. **Where do I report issues?**

   Report issues on our GitHub issues page: https://github.com/your-tango-repo/issues
