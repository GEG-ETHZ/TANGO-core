TANGO Tutorials
===============

Step-by-step tutorials to help you understand and use TANGO effectively.

Tutorial 1: Setting Up and Running Your First Stream
----------------------------------------------------

In this tutorial, you'll learn how to:
1. Create a new stream.
2. Run simulations with basic configuration.

.. code-block:: python

   from tango.core import Stream

   stream = Stream(name="example_stream")
   stream.run()

See the full tutorial here: :doc:`tutorials/tutorial_1`.
